# What's On category tile art (needed)

Twelve 1376×768 (16:9) lossy WebP images, one per category key, following the
`/images/outdoors/<key>.webp` convention. The card renderer
(`whatsOnCategoryImagePath` in `server.js`) emits an `<img>` only when the file
exists; until then each tile renders the on-brand navy fallback with its line
icon. Imagery should be specifically Okanagan — no generic stock event photos.
